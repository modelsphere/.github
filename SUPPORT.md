# Getting help

| You have | Go to |
|---|---|
| A question about installing or running ModelSphere | Read the [install guide](https://github.com/modelsphere/modelsphere/blob/main/docs/install.md) and the component's README first, then open an issue in [modelsphere](https://github.com/modelsphere/modelsphere/issues) |
| A bug | An issue in the repository of the component that misbehaves (see [CONTRIBUTING.md](CONTRIBUTING.md#where-a-change-belongs)) |
| A feature idea | A feature request issue in that repository |
| A security problem | **Not** an issue — see [SECURITY.md](SECURITY.md) |

When you ask, include the versions involved (component, Helm chart,
Kubernetes, accelerator and driver), what you ran, and what it printed. Redact
hostnames, IPs and credentials.

Public issues are answered on a best-effort basis; there is no guaranteed
response time.
